# Score 5 - Inteligência Comercial

Sistema de análise desenvolvido para ajudar representantes comerciais a acompanhar seu desempenho e alcançar suas metas em clientes específicos da base Ambev.

## Sobre o projeto

O Score 5 - Inteligência Comercial tem como objetivo facilitar o acompanhamento de indicadores comerciais, permitindo analisar resultados e identificar oportunidades para melhorar o desempenho no cumprimento das metas.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Node.js

## Como executar o projeto

Primeiramente, clone o repositório:

```bash
git clone https://github.com/Gilvandro09am/Score-5_Inteligencia_comercial.git
```

Entre na pasta do projeto:

```bash
cd score5-inteligencia-comercial
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra o navegador e acesse:

```text
http://localhost:3000
```

## Desenvolvimento

Para começar a modificar o projeto, edite os arquivos dentro da estrutura da aplicação Next.js. As alterações serão atualizadas automaticamente durante a execução do servidor.
